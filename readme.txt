Un plugin de pasarela de pago minimalista, robusto y 100% Server-to-Server para WooCommerce.

== Description ==

Desarrollado y optimizado por soyprogramador.pe.

Este plugin integra la pasarela de pagos Culqi V4 utilizando una arquitectura pura de Backend (API Server-to-Server). A diferencia del plugin oficial, esta versión elimina dependencias pesadas de Javascript en el frontend e interactúa directamente con el core nativo de WooCommerce, ofreciendo una experiencia de pago fluida, rápida y libre de conflictos.

= Características Principales =
* Arquitectura Server-to-Server.
* Soporte Completo 3DS (Autenticación).
* Checkout Minimalista y Nativo.
* Detección Automática de Marca (SVGs Locales).
* Selector de Tarjetas de Prueba Integrado.

== Installation ==

1. Sube la carpeta `culqi-payment` al directorio `/wp-content/plugins/` de tu instalación de WordPress.
2. Ingresa a tu panel de administración de WordPress y ve a Plugins.
3. Busca "Culqi Payment Server-to-Server" y haz clic en Activar.
4. Dirígete a WooCommerce > Ajustes > Pagos y configura tus llaves.
